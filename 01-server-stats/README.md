# 📊 Server Stats Monitor

Script Bash untuk memantau performa server Linux secara real-time.

## Fitur
- CPU, Memory & Disk usage
- Top 5 proses tertinggi (CPU & RAM)
- Uptime, OS info, dan login activity

## Cara Pakai

```bash
git clone https://github.com/rifkiaf.git
cd 01-server-stats
chmod +x server-stats.sh
sudo ./server-stats.sh
```
